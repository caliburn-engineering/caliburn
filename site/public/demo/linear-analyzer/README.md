# linear-analyzer — a frozen bundle

Every other demo under `public/demo/` is build output, gitignored, and
regenerated by `../../sync-demo.sh`. This one is neither, and is tracked in git.

The merge that produced Ball-Balancer (issue #15) removed the analyzer-only
build path from the project tree, so nothing can rebuild these files. They are
the last copy of the standalone analyzer, and the reason both demos stay
published — issue #11 keeps this one live so the site is never without
something working. Deleting the directory does not lose a build artifact; it
loses the artifact.

`visualizer.html` is hand-edited, and only that file. The analyzer reads its
dock layout from `imgui.ini`, which the desktop build finds on disk and this
build never had: every panel opened floating at ImGui's default position, all
six stacked on the same spot, which is how the demo looked from the day it was
published until the fix. The shell now seeds a layout into the virtual
filesystem in `preRun`, before the runtime starts. The wasm, js and data are
byte-for-byte as `emcc` emitted them.

Do not run the bundle through a minifier or a formatter — the injected layout
and the comment explaining it are the only record of why this file differs from
what the build produced.
